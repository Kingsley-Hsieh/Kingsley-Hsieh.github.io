AI-Driven NPC Dialogue System with Emotional Memory

About the Game

An Open-Ended, Memory-Augmented Social RPG Sandbox

This project introduces an engine-agnostic dialogue framework designed to replace static, predictable dialogue trees with responsive, open-ended NPC interactions. Set in a focused social sandbox, players can freely converse with a cast of 3–5 distinct NPCs whose attitudes, trust, and available tasks evolve dynamically based on how you treat them across play sessions.

Key Features

  • Persistent Emotional Memory: NPCs remember past player actions, conversations, and experiences. Their evolving mood and relationship levels shape how they treat you in future interactions.
  • Local, On-Device AI Processing: Powered by quantized local language models running via Ollama, the dialogue system processes conversations entirely on the player's device. This ensures strict privacy, zero recurring API costs, offline availability, and zero reliance on cloud servers.
  • World Consistency & Smart Guardrails: To eliminate narrative contradictions, an engine-agnostic middleware filters model outputs. An explicit lore database prevents characters from inventing non-canon facts, while a deterministic rule engine ensures all quest progression, inventory trades, and relationship changes remain fully bound by game logic.
  • Responsive, Low-Latency Streaming: Designed for smooth gameplay, custom performance optimizations—including prompt caching, speculative decoding, and predicted-response caching—deliver fluid, real-time response generation without freezing the game UI.
